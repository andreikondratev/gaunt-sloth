# v2.0.0

- **`gth exec`, `gth batch`, `gth eval` and `gth workflow` run Gaunt Sloth without a session.**
  `exec` runs a markdown prompt-executable once and pipe-clean, `batch` fans one across a matrix of
  inputs and models, `eval` grades agent output against suites with judges and metric gates, and
  `workflow` drives several agent calls from a local JavaScript script.
- **`gth config`, `gth models`, `gth history` and `gth insights` are new local surfaces, taking the
  CLI from eight commands in 1.x to sixteen with all eight still there.** `config` prints and
  validates the resolved configuration, `models` lists each provider's models with cost and
  context-window metadata, and `history` and `insights` search and summarise recorded sessions.
- **`gth chat` and `gth code` open a full-screen terminal interface** — scrollable transcript,
  collapsible reasoning, and a multi-line editor with bracketed paste and slash-command completion.
  Mouse reporting is on by default, so hold Shift while dragging to select text as your terminal
  normally would or turn it off with `/mouse off`; `--no-tui` keeps the plain readline surface, and
  both surfaces share one slash-command registry.
- **Shell execution runs behind one ordered ladder of five approval modes** — `manual`, `write`,
  `assisted`, `auto`, `bypass` — replacing the 1.x `yolo`, `judge` and `allowlist` flags. A safety
  rater classifies each proposed command, and a deterministic floor refuses the worst of them before
  any model is consulted.
- **Sessions are recorded locally and can be resumed — nothing leaves the machine, and
  `history.enabled: false` turns all of it off.** Runs are written to `~/.gsloth/history.db`,
  `--resume <id>` or `/resume` picks a conversation up where it left off, and `/compact` folds a
  long one down, as the session itself now does once when a turn overflows the model's context
  window instead of ending the turn.
- **Configuration is validated strictly against a single schema.** `gth config validate` checks a
  config without building an LLM or running anything, a `.gsloth.config.ts` exporting `configure()`
  is supported alongside the JSON and JavaScript forms, and the project config is now found by
  walking up from the directory you run in.

## Breaking Changes

Before upgrading a 1.x config, read [docs/MIGRATION.md](https://github.com/pukeko-robotics/gaunt-sloth/blob/v2.0.0/docs/MIGRATION.md) and check the result with `gth config validate`.

- **The package is renamed: 2.0 installs as `gaunt-sloth`, where the 1.x package is
  `gaunt-sloth-assistant`.** Run `npm rm -g gaunt-sloth-assistant` before `npm i -g gaunt-sloth` —
  installing over the old package can abort the entire install over a bin name it already owns,
  after which `gth --version` goes on quietly reporting the 1.x version.
- **Deprecated config shapes are now hard errors, with no back-compat coercion:** a boolean
  `rating`, a top-level command key, a `*Provider*` name, per-command `devTools`, the flat prompt
  keys, the old approval knobs, a boolean `output.header` and a `video` or `binary` entry in
  `binaryFormats` each abort the run. Fix them before you upgrade; every message names its
  replacement.
- **Three defaults changed without raising any error.** `output.header` now defaults to `compact`,
  so a text run opens with one attribution line instead of the old preamble; `writeOutputToFile`
  now defaults to `false`, so the `gth_<timestamp>_<COMMAND>.md` report files are no longer written;
  and session history is on — set each one back explicitly if you relied on it.
- **The AG-UI server binds `127.0.0.1` rather than every network interface, because the endpoint
  carries no authentication.** This narrows a local client too — one that dials `localhost`,
  resolves it to IPv6 and does not fall back gets a connection refused, so pass `--host ::1` for
  that, or `--host 0.0.0.0` to serve another machine.
- **Some surfaces are gone.** `agent.backend: "deep"` and its exports are removed; the `gaunt-sloth`
  package no longer exports modules, so embedders import from `@gaunt-sloth/core`,
  `@gaunt-sloth/agent`, `@gaunt-sloth/review` or `@gaunt-sloth/batch` instead; and `/tools`,
  `/mode`, `/yolo`, `/auto-approve` and `/bypass-approve` are replaced by `/verbose`, `/status` and
  `/approvals`.
