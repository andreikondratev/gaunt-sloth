# v2.0.0-beta.13 Saying What Happened

- A run that ends without an error can now say what it did. The new `recap` key — `off` (the
  default), `outstanding` or `always` — turns the one stop that looks like success into a short
  block naming the goal, what the run did and what is still outstanding. It reports and never
  continues the run.
- A silent wait now says what it is waiting for: a rated command used to hold the turn for the
  whole rater budget while the status bar still reported the model as thinking. Alongside it, a
  provider refusal renders as a sentence naming the condition and the remedy, rather than the
  provider's own explanation buried in a serialized object.
- Esc interrupts on the non-streaming turn path, which had no interrupt at all — a runaway call
  there showed only a spinner. Cancelling now says so instead of returning an empty answer.
- A shell call can ask for more time, through an optional `timeoutMs` on `run_shell_command` and
  the `run_*` tools, bounded by a configurable ceiling. A request over the ceiling is refused
  before anything runs, and a command killed by its budget now says it was killed — which is not
  the same as failing.
- A bare `/resume` offers the resumable conversations as a keyboard list — arrows to move, Enter
  to resume, Esc to stay — instead of printing ids to retype. An unknown slash command names the
  command you probably meant.
- The `/debug` pane has an Auto-mode tab naming which stage decided each gated command, so a
  report can distinguish a rater verdict from a floor match or a deny-list hit.
- A configuration that names no model is refused with a message saying so, at every entry point
  rather than only where the config is read; it no longer crashes under the verbose flag, and
  printing a configuration still works without one.
- The AG-UI server answers a capabilities endpoint at `/agents/:agentId/capabilities`. The
  API-reference site now carries the module documentation that a block-tag quirk had been
  deleting before render, with the broken links that exposed repaired.

## Potentially Breaking Changes

- Building an agent that can interrupt without a checkpointer is now refused at construction
  rather than failing later. This reaches embedders constructing an agent directly: pass a memory
  saver. An agent that cannot interrupt is unaffected.
