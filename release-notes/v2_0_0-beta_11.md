# v2.0.0-beta.11 Evals Get Their Instruments

- `gth eval` now reports **tool coverage**: how many of the tools the agent actually loaded your
  suite exercised, with the uncovered names listed in full and a per-server breakdown. A suite can
  be entirely green while touching three of a server's forty-one tools, and nothing said so before.
  It can also gate — `tool_coverage` takes a `min` floor, a `require:` list of globs that must be
  exercised, and `waive:` for tools deliberately never evalled, which are removed from the
  denominator. Tools excluded by `allowedTools` are reported as their own category rather than
  quietly shrinking the fraction.
- `--compare-to` now reports **judge-score drift** beside verdict flips. A cell sliding 10 → 8 → 7
  against a `pass_threshold: 6` used to report "no change" three times and then fail on the fourth
  run with no warning that it had been degrading. The default reports a case when its score crossed
  the threshold; `--drift threshold-ward:<n>` widens that band and `--drift mean` compares against
  the run's mean instead. The default is deliberately narrow because judge scores wobble between
  identical runs by about a point, and a section that fires on noise is one people learn to skip.
- **A denied MCP tool call now reaches the eval tool trace**, so `must_error` can grade it. A softened
  error result carried no tool name, and the run-stats harvester records a result only for a named
  message, so denials and failed shell commands were dropped entirely.
- **An alignment check that could not be reached now says why.** All four fail-closed causes rendered
  the same sentence naming none of them, and a provider's own rejection was discarded, so a sweep
  could record ten failures with no reason recorded anywhere. Each cause now carries its own reason
  and the provider's account. What the check decides is unchanged.
- Every published release is now installed from npm on a clean runner and all three binaries are run,
  so a broken publish is found in minutes rather than by whoever installs it next.
