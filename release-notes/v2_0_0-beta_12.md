# v2.0.0-beta.12

- `tool_result_json_path` can now grade **what an MCP tool's denial said**, not merely that one
  happened. The MCP adapter hands a failed call back as a prose-wrapped message, which never parsed
  as JSON, so an authorization suite could prove a call was refused and never assert on the error
  code or reason inside it. The server's own error body is now recovered alongside the result and the
  check reads it. What the model observed is recorded unchanged beside it, so the trace is still
  evidence of what the agent was reacting to.
  One limit worth knowing: the adapter discards an errored tool's `structuredContent` before we see
  it, so a server that carries its error detail only there is still not gradable. That is upstream.
- The two API reference links on the configuration page pointed at the retired 1.x documentation
  layout and returned 404. They now resolve.
